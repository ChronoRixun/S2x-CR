# Isolated native client economy QA

These Lua probes are manual QA fixtures, not production UI scripts. They change synthetic progression/currency and navigate the game. Install a probe only under an isolated scratch client's `s2x/ui_scripts/mp/economy_live_qa/__init__.lua`, with an explicitly named disposable `-profile`, a separate `-appdata-dir`, automatic updates disabled and master discovery disabled. Never run them against an installed client, existing player profile or deployed server. They are not included in release `data`.

Use the stock terminal `lui_restart` command to reload a probe in an already-loaded QA client. Native engine calls can return zero Lua values before world readiness; assign the result locally or parenthesize the call before formatting. Wait for readiness and cache completion when interpreting shop population. The shop probe uses a temporary, unsaved `master_server` phase marker while discovery is disabled.
