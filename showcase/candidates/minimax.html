Requires a legitimate Steam copy of Call of Duty: WWII. S2x doesn’t ship the game files and doesn’t get around needing them — it patches and hosts what you already own. Own it on Steam first, or this build is a doorstop.

What you’ll do in fifteen minutes

Four steps, and none of them are a leap of faith

  1. Own Call of Duty: WWII on Steam. If it’s already in your library, you’re most of the way there.
  2. Drop the S2x release into the game folder — the one with s2_mp64_ship.exe in it.
  3. Launch Steam, then run s2x.exe. It finds the rest.
  4. The server browser opens. Pick a server — or start a custom match with bot_fill 17 and fill every seat.
