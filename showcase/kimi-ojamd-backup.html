Read this first · 30 seconds

The game you own stopped working. This puts it back.

Call of Duty: WWII (2017) is effectively dead on retail: matchmaking is empty and the progression servers are gone, so even if you find a lobby, nothing ranks up and nothing drops. S2x is a community-built custom client that re-implements what was switched off. S2x-CR is ChronoRixun’s fork of it — current version v1.3.0 — focused on bots that actually show up, a dedicated server that starts every time, and a local Headquarters economy that pays out like the retail game did.

Everything below is a real capture from the fork. Every caption carries the timestamp it was taken. If a claim can’t be backed by a screenshot or the changelog, it isn’t on this page.

An empty server is only empty until you spawn.

Also fixed: bots in offline Custom Matches

Retail Local Play accepted bot settings and then never spawned them. The fork routes bot_fill and spawnBot through the game’s own spawn script on listen servers, so bots pick teams and classes and actually walk onto the map — capped at 17 plus the host. Practice lobbies work again.

Phase 03 · Every match pays

The Headquarters economy, running locally.

Orders, contracts, payroll, supply drops, the Quartermaster and Mail — all re-implemented over the Achievement Engine protocol, on your machine, no dead servers involved. Earn Armory Credits, work the boards, open drops. It behaves like 2017 because it’s the same UI doing the same math.

The part retail stopped paying

Every soldier level-up credits the Rare Supply Drop the end-of-match screen always promised. The game reported the level-up for years; the fork’s economy is what finally makes it true — on dedicated servers and in Local Play alike.

For the second kind of reader

Got a spare PC? You’re a host.

Every server in that browser is someone’s spare box. The bundled WPF launcher is the whole job: it finds the game folder on its own, so a machine with the game files copied over — no Steam installed — becomes a dedicated server in one click.

  • One window, both modes.

    A toggle flips between Multiplayer and Zombies, with presets saved per mode.

  • Your rotation, your rules.

    Pick maps, gametypes, score limits and bot settings before you launch.

  • Name it in colour.

    A swatch row inserts ^1 red, ^3 yellow, ^7 white at the cursor, with a live preview. Those coloured host names in the browser? Set here.

  • Then hit Launch.

    The launcher locates the game folder itself. Copy the files to any Windows box and it’s a server.

From the fix log

40 / 40cold starts to a full match

Roughly one dedicated-server launch in ten used to die a few seconds in. The cause: a repair guard in the game’s anti-tamper layer quietly restored three of the client’s own patches, after which an integrity check failed and killed the process.

The guard is now filtered like the rest. Forty cold starts in a row reached a full match with bots — against nine of ten before the fix.

For developers & the skeptical

S2x-CR is a fork of Brentdevent/S2x; the diff is public. Bots route through the game’s own GSC spawn script on listen servers. The Headquarters economy is a local re-implementation over the Achievement Engine protocol. The anti-tamper repair guard is filtered, not removed. Open the issue tracker if you want the unvarnished version — it’s all there.
